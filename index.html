Changelog
v1.1Mar 2026
Cardio support
  • Per-exercise type toggle: Weights or Cardio
  • Cardio exercises track duration (min) and distance (km)
  • Mixed workouts supported — weights and cardio in same plan
  • Stats: total cardio minutes and total distance added to summary grid
v1.0Mar 2026
Initial release
  • Plan → train → complete workflow with reusable plans
  • 5 tabs: Plan, My Plans, Workout, History, Stats
  • kg / lbs unit toggle throughout
  • Exercise accordion with sets, reps and weight builder
  • Plan numbering, editing, copying and one-time-use on completion
  • Global workout numbering (#1, #2, #3…)
  • Abandoning a workout restores the plan to My Plans
  • History: Timeline and Progress views with workout name filters
  • Year and month date filters on History and Stats
  • Stats: volume, progression chart, personal bests, most trained
  • Typo protection: auto title-case, fuzzy match warning on entry
  • Exercise library with duplicate detection, inline rename and quick-select
  • Data export and import via JSON backup file
  • Ember dark theme
